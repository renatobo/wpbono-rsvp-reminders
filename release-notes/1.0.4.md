# WPBono RSVP Reminders 1.0.4

## New Features
- None.

## Improvements
- Added 15 scheduling regression tests on the supported CI PHP matrix.
- Process reschedule resets in stable batches so affected attendees beyond the normal sweep limit are included.

## Bug Fixes
- Dry-run previews no longer write real sent markers or suppress subsequent real reminders.
- Editing repeating schedules resets only occurrence indices whose start changed or disappeared. Appending dates and end-time-only changes preserve existing reminders.
- Corrected dry-run onboarding and settings guidance.

## Upgrade notes
- Existing markers created by older dry runs are preserved because they cannot reliably be distinguished from actual sends. Review activity history before targeted recovery.
- No historical schedule migration is needed: the old occurrence starts are captured before each WordPress metadata write. Changes made directly in SQL bypass these hooks.
- Repeat-index changes are treated as schedule changes when the start at that index differs. EventON/RSVP runtime compatibility still requires integration verification.
